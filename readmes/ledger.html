Ledger

A Discord bot I wrote to keep track of a balance, who owes what, and how much stock is left of each item. Everything runs through slash commands, buttons and pop-up forms, and every change gets written to a history log you can filter and export.

Commands

Command What it does
/ledger Shows the balance, total owed, associate and asset counts, and the last 7 history entries. Buttons to increase, decrease or set the balance and to export the full history as a text file.
/wipe Clears all data after a confirm button.
/tab Lists associates sorted by debt, with buttons to add or delete one.
/associate Pick an associate from a dropdown to change their debt or export their history.
/assets Lists assets sorted by stock, with buttons to add or delete one.
/asset Pick an asset to change its stock, edit its name, unit and thumbnail, or export its history.

Amounts can be decimals. Each associate and asset gets a short random ID, and the dropdowns show the first 25.

There are no permission checks on any command, so anyone in the server who can use slash commands can change the numbers or wipe everything. Keep it in a server you trust.

Storage

Data lives in ledger.json in the folder you run the bot from, through TinyDB. It has four tables (ledger, tab, assets, history) and is created on first run. It's in .gitignore.

Setup

You need Python 3.13 or newer, uv, and a bot application from the Discord Developer Portal.

The bot turns on the Message Content intent, so enable it under Bot > Privileged Gateway Intents or the login fails. Invite the bot with the bot and applications.commands scopes.

git clone https://github.com/stafawashere/ledger.git
cd ledger
uv sync

Create a .env file in the project root:

DISCORD_TOKEN=your_bot_token

Run it from the project root, since the cog folder and ledger.json are found by relative path:

uv run bot.py

On startup it loads every folder in cogs/ and syncs the slash commands. While it's running, it watches cogs/ with watchfiles and reloads a cog when one of its files changes, so I didn't have to restart it while working on the UI.

Layout

bot.py               startup, cog loading, hot reload
cogs/ledger/         /ledger, /wipe, balance and history export
cogs/tab/            /tab, /associate
cogs/assets/         /assets, /asset
utility/database.py  TinyDB tables and the history log
utility/embeds.py    embed helpers
utility/views.py     dropdown wrapper
utility/__init__.py  ID generation, number parsing and formatting
